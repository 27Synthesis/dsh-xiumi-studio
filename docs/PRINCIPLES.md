# 工程约束（插件底层规矩）

这份文件是《如何用 AI 长期开发一个复杂项目》里那七条原则在本项目里的落地版。不是读后感，是**每次改动都要过的检查**。改代码前读一遍对应的一条；发现新坑，就往里加一行。

## 1. 样式与数值只有一个来源

**规则**：颜色、字号、行距、圆角、间距，只允许出现在 `host/themes.mjs`（主题）与 `host/render.mjs` 顶部的 FONT/常量里。任何新页面、新面板、新块类型，都不许另写一套色值。

**为什么**：项目失控的第一症状就是「样式各自实现」——新功能不复用现有组件，几周后同一份界面出现三种红。

**自检**：`grep -n '#[0-9A-Fa-f]\{6\}' host/ client/` 的结果里，除 themes.mjs 与 render.mjs 头部外不该有第二处色值；出现即为违规。

## 2. 不写死设备与尺寸假设

**规则**：手机宽度是 390px 的阅读宽度；图片一律 `max-width:100%`；多列宽度和不得超过 100%；字号用相对可读区间（正文 14–16px、一级标题 21–24px、注释 10–12px）。封面是 900×383（公众号首图标准）与 500×500（分享方图），不允许"大概 900 多"。

**为什么**：固定数值散落在代码里，换设备就暴露兼容问题；公众号侧的编辑器还会二次缩放。

## 3. 同一件事只实现一次

**规则**：预览、导出、发布三条路**必须**共用 `renderFragment` / `renderPage`。面板里看到的 HTML 与发出去的 HTML 是同一份字节。禁止为面板另写一套渲染。

**为什么**：第二套渲染一定会在某个块类型上分叉，然后出现"面板好看、发出去变形"——这类 bug 极难查，因为两边都"看起来对"。

## 4. 不留多余实现

**规则**：删掉的块类型、废弃的路由、试验性的主题，一次改完就删干净，不留兜底分支和"也许以后用得上"的开关。兜底逻辑只在**有真实失败场景**时写（例如 MCP 字段按 schema 适配、Python 缺失时报错），并且必须写明它防的是什么。

## 5. 文档跟着代码走

**规则**：改了路由、工具参数、主题 id、技能步骤，同一次改动里更新 `README.md`、`skills/xiumi-studio/SKILL.md`、本文件。**过期文档比没有文档更贵**：模型读完旧文档还要重新读代码判断，人更难发现。

**自检**：每次交付前对照 `host/tools.mjs` 里的工具清单，逐条核对 SKILL.md 中提到的工具名与参数是否仍然存在。

## 6. 先给可读方案，再动手

**规则**：涉及"改变界面结构 / 改变发布链路 / 改主题体系"的改动，先写清楚：界面会变成什么样、走什么实现、改哪些文件、特殊情况怎么处理、哪些决定要人拍板、怎么验收。方案让人看懂再执行；执行完由人手动点一遍（机器测跑通与性能，人测手感）。

## 7. 把踩过的坑变成硬约束

**规则**：重复出现两次的错误，写进本文件或 SKILL.md，并尽量变成代码里的断言/校验（例如 `xiumi_preview` 的"未用上素材"警告、导入时对图片数量的核对）。发布会出问题的地方留退路：发布失败必须给出可执行的下一步（授权 / 改 schema / 离线粘贴），而不是只报错。

**已固化的坑（2026-11-15）**：
- `host/routes.mjs` 里有一句 `if (req.method !== 'POST') return fail(res, 405, '方法不支持')` 当「写方法区」的门，**GET 路由必须写在它前面**；写在后面会永远 405（`/xiumi/api/health`、`/xiumi/api/template/shows` 都栽过）。
  → 新加 GET 接口后，用 `_inspect/probe-routes-stub.mjs` 起独立服务打一遍，再对真宿主 curl 一次；两道都过才算通。
- 宿主侧代码改动**不会被 touch 触发重载**，必须走 `_inspect/reload-test.mjs --yes --port <端口>`（会改 profile 配置，脚本自带备份/还原）或在插件市场里关掉再打开。

## 8. 疑难点及时止损

**规则**：同一个 bug 连续两轮没修好，停下来重新判断问题本身（是不是方向错了），把判断和置信度写给人看，由人决定换方案还是砍功能。不要用"再试一次"堆工作量。

## 与产品需求对应的硬约束

| 需求 | 代码位置 | 表现形式 |
| --- | --- | --- |
| 文稿不许删改 | `host/tools.mjs` 工具描述 + SKILL.md 第 3 节 | 工具只暴露结构/图注/小标眉的修改面；正文改动需人确认 |
| 图片必须全部用上 | `xiumi_preview` | 有未落位素材直接给出 ⚠ 警告 |
| 直接出现在「我的图文」 | `host/xiumi.mjs` + `xiumi_publish` | MCP 投递；失败给离线粘贴方案 |
| 能实时看到创作过程 | `client/studio.js` + 右栏面板 | 2500ms 轮询工程文件，块级变化即时可见 |
| 工作流内置、不跑偏 | `skills/xiumi-studio/SKILL.md` | 装好插件即注册技能，模型按步骤执行 |
| 一眼能看懂的预览 | `host/render.mjs` | 手机框 390px、与最终产物同一实现 |
