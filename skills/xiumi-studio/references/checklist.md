# 自检清单（打印版）

发布前从上到下打勾，任何一项打不上就不发。

- [ ] 工程 id 与标题正确，不是上一个任务的残留
- [ ] 图片：材料 N 张，正文 N 张，无未用素材警告（面板「素材」应显示 `N / N 用上`）
- [ ] 段落：原稿段落数 = 正文档数（拆分/合并已能逐条解释）
- [ ] 文稿：没有任何一句被删改（错别字/空格除外，且已在回复中说明）
- [ ] 小标题编号连续（01、02、03…），没有跳号，也没有「01 01 …」这种重复（重复说明原稿自带的编号被加了两次）
- [ ] 图注只含客观信息，不含编造的人名/职务/日期
- [ ] 主题与内容气质匹配，封面配色与正文一致
- [ ] 手机宽度预览无横向滚动，段落没有超过 6 行的"字墙"
- [ ] 结尾落款/编辑信息齐全（或已问过用户不需要）
- [ ] 发布结果已确认，或已明确告知用户走离线粘贴

## 常见返工原因（来自真实任务）

| 现象 | 原因 | 正确做法 |
| --- | --- | --- |
| 封面还是旧颜色 | 换了主题没重绘 | 换主题后立刻 make_cover |
| 图少了一张 | docx 里的图没落在块里 | preview 看"未用上的素材" |
| 标题在小屏被截断 | 封面标题太长自动降字号到极限 | 调断行，不改字 |
| 秀米里图片裂开 | 发布用了外链而不是内嵌 | 用 embed 模式渲染（base64 内嵌） |
| 发布了但"我的图文"里没有 | 工具返回成功但草稿未保存 | 让人在秀米页面确认，必要时走离线粘贴 |
